# MOEX Analytics Platform

Аналитическая платформа для автоматизированной загрузки, хранения,
обработки и анализа данных Московской биржи и Банка России.

## Текущий стек

- Python
- PostgreSQL 17
- Docker Engine
- Docker Compose
- DBeaver
- Git и GitHub

## Текущий статус

Настроено локальное окружение разработки и запущен PostgreSQL
в Docker-контейнере.
