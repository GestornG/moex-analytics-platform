# Dashboard — Stock Analysis

**Проект:** MOEX Analytics Platform
**Платформа:** Open Source DataLens
**Статус:** реализован

## 1. Назначение

Интерактивный анализ отдельной акции Московской биржи за выбранный период: динамика котировок, доходность, торговая активность, просадки и корпоративные события.

## 2. Структура дашборда

| Компонент | Содержание |
|---|---|
| Селекторы | Акция (`secid`), период исследования |
| KPI | Начальная, конечная, минимальная и максимальная цены; доходность; дивиденды на акцию |
| Графики | Динамика цены, недельный денежный оборот, месячная доходность, просадка |
| Таблицы | Дивиденды, сплиты и консолидации |

Селекторы синхронизированы между визуализациями нескольких датасетов.

## 3. Методика расчётов

| Показатель | Методика |
|---|---|
| Скорректированная цена | Исходная цена × коэффициент корректировки на сплиты |
| Начальная цена | Цена открытия первого доступного торгового дня с положительной ценой |
| Конечная цена | Цена закрытия последнего доступного торгового дня |
| Доходность, % | `(Конечная / Начальная − 1) × 100` |
| Минимальная / максимальная цена | `MIN / MAX(close_adj)` |
| Недельный оборот | Сумма `value` по неделям |
| Месячная доходность | Изменение цены закрытия относительно предыдущего месяца |
| Просадка, % | `(close_adj / накопленный MAX(close_adj) − 1) × 100` |
| Дивиденды, ₽/акц. | Сумма рублёвых эквивалентов дивидендов за период |

Ценовая доходность не включает дивиденды. Дивидендные события относятся к периоду по дате закрытия реестра.

## 4. Источники данных

**PostgreSQL:** `dwh.security`, `dwh.security_daily`, `dwh.dividend`, `dwh.split`, `dwh.currency`, `dwh.currency_rate`.

Для корректировки цен используется SQL-представление `analytics.v_split_factors`.

**Датасеты DataLens:**

| Датасет | Назначение |
|---|---|
| `security_daily_analytics` | История скорректированных цен и торговая активность |
| `security_dividends` | Дивидендные события и рублёвый эквивалент |
| `security_splits` | Сплиты и консолидации |

SQL-запросы датасетов расположены в каталоге [`sql/datalens/`](../../sql/datalens/).

## 5. Результат

Реализован единый аналитический экран для исследования исторической динамики акций, оценки ценовой доходности и торговой активности с учётом корпоративных событий.
