# Analytics — описание аналитических объектов

## `v_split_factors` — коэффициенты корректировки исторических цен

**Назначение**

Интервальный справочник накопленных коэффициентов корректировки цен акций на сплиты и консолидации.

Используется при формировании аналитических ценовых рядов без изменения исходных данных DWH.

**Источник**

`dwh.split` — история сплитов и консолидаций акций.

**Расположение**

`analytics.v_split_factors` — обычный PostgreSQL VIEW.

**Зерно**

Одна строка = один период действия накопленного коэффициента корректировки одной акции.

**Формирование**

1. Для каждого события рассчитывается индивидуальный коэффициент `ratio_before / ratio_after`.
2. События каждой акции упорядочиваются по дате от новых к старым.
3. Коэффициенты последовательно перемножаются для получения накопленного коэффициента.
4. Для каждого результата формируется интервал применения.
5. Периоды с накопленным коэффициентом `1` исключаются.

**Правила периодов**

- `date_from` — нижняя граница, включительно.
- `date_to` — верхняя граница, исключительно.
- `NULL` в `date_from` — отсутствие нижней границы.
- Дата события `dwh.split.trade_date` считается началом торгов в новой шкале цен.
- Для дат после последнего события корректировка не требуется, соответствующая строка не создаётся.

Правило верхней границы проверено на дневных котировках `security_id = 4` и `10`.

**Использование**

Справочник присоединяется к дневной истории по `security_id` и попаданию `trade_date` в интервал `[date_from, date_to)`.

Используется `LEFT JOIN`. При отсутствии подходящего коэффициента применяется `COALESCE(split_factor, 1)`.

**Особенности и ограничения**

- Не хранит исторические цены и объёмы.
- Не содержит акции без корпоративных событий.
- Учитывает несколько последовательных событий одной акции.
- Коэффициенты вычисляются относительно последнего учтённого события.
- Обычный VIEW не требует `REFRESH`: новые данные DWH учитываются при последующем запросе.
- Достоверность результата зависит от полноты и корректности `dwh.split`.
- Требует положительных ненулевых значений `ratio_before` и `ratio_after`.
- Не учитывает дивиденды.
- Не применяется автоматически к минутным свечам: для них выявлены признаки уже скорректированной истории, но методология источника полностью не подтверждена.
