# MOEX Analytics Platform

Учебно-практический проект аналитической платформы для загрузки, хранения и последующего анализа данных российского финансового рынка.

Проект объединяет данные Московской биржи, Банка России и T-Invest, преобразует их в Python ETL и загружает в PostgreSQL DWH. Следующие этапы проекта — построение аналитического MART-слоя и визуализация данных в Apache Superset.

## Архитектура

```text
MOEX ISS ─────┐
CBR API ──────┼──> Python ETL ──> PostgreSQL DWH ──> MART ──> Superset
T-Invest API ─┘
```

Постоянный RAW/SOURCE-слой в PostgreSQL не используется: данные получают из API, очищают и преобразуют в Python, после чего загружают непосредственно в DWH.

## Текущий статус

На текущем этапе реализованы:

- исследование и отбор источников данных;
- логическая и физическая модель DWH;
- PostgreSQL-схема `dwh`;
- API-клиенты для MOEX, Банка России и T-Invest;
- ETL-процессы для всех таблиц текущей модели;
- инкрементальная загрузка исторических данных там, где она оправдана;
- идемпотентная запись через `UPSERT`;
- централизованное логирование;
- конфигурация scope проекта отдельно от секретов.

Сейчас проводится финальный аудит и рефакторинг ETL-слоя. После него планируется собрать единый pipeline, зафиксировать ETL-дизайн в документации и перейти к MART и Superset.

## Источники данных

| Источник | Используемые данные |
| --- | --- |
| MOEX ISS | справочник акций, индексы, дневная история торгов, минутные свечи, сплиты, состав индексов |
| Банк России | справочник валют, валютные курсы, ключевая ставка |
| T-Invest REST API | внешний UID инструмента и дивидендные события |

Основные источники являются внешними API. Сырые ответы отдельно не сохраняются.

## Scope проекта

Текущий scope задаётся в `config/scope.toml` и включает:

- 20 акций основного режима торгов `TQBR`;
- индекс МосБиржи и 4 отраслевых индекса;
- USD и CNY из API Банка России;
- исторический период `2020-01-01` — `2020-06-30`.

Scope вынесен в конфигурацию и может расширяться без изменения ETL-логики.

## DWH

В PostgreSQL используется схема `dwh`.

| Таблица | Назначение |
| --- | --- |
| `security` | справочник акций |
| `index` | справочник индексов |
| `calendar` | календарный справочник |
| `currency` | справочник валют |
| `security_daily` | дневная история торгов акций |
| `index_daily` | дневная история индексов |
| `candle_1m` | минутные свечи акций и индексов |
| `dividend` | дивидендные события |
| `split` | сплиты и консолидации акций |
| `index_composition` | история состава индексов |
| `currency_rate` | история валютных курсов |
| `key_rate` | история ключевой ставки Банка России |

Подробное описание зерна, ключей, связей и правил загрузки находится в `docs/data_model.md`, а состав полей — в `docs/data_dictionary.csv`.

## ETL

ETL-слой разделён на три основные части:

- `api/` — получение исходных данных и обработка HTTP-запросов;
- `db/` — чтение из PostgreSQL и запись в DWH;
- `etl/` — бизнес-логика загрузки и преобразование данных к модели DWH.

В загрузках используются:

- пагинация MOEX ISS;
- retry для временных HTTP-ошибок;
- параметризованные SQL-запросы;
- `UPSERT` для повторяемой загрузки без дублирования;
- диапазонная инкрементальная загрузка исторических наборов;
- полный повторный reload небольших наборов там, где дополнительная инкрементальная логика не даёт практической выгоды;
- `Decimal` для денежных значений, где требуется точное преобразование;
- централизованное логирование в консоль и файл.

## Конфигурация и секреты

Бизнес-параметры проекта хранятся в `config/scope.toml`.

Секреты и параметры локального окружения хранятся в `.env`, который исключён из Git. Пример переменных окружения находится в `.env.example`.

T-Invest используется через sandbox endpoint. Токен не хранится в исходном коде и передаётся через переменную окружения `T_INVEST_TOKEN`.
